# Strawberry DNA Extraction webpage — implementation outcomes

- [x] **Balanced diagrams and readable text** — Instructional figures and process illustration were previously scaled down to half size; the latest update makes every diagram 30% larger than that current state. Inline figures render at 65% width with a 494px cap (423px in application cards); the process strip is 65% with a 351px cap; the 22-image archive uses a 65%-width image area and 416px desktop height, with matching +30% mobile sizing. Aspect ratios are preserved. Long-form paragraphs and table copy stay at least 30px, while navigation and metadata retain their intentional compact sizes.
- [x] **Clear methodology** — A before-you-start checklist identifies reagents, equipment and safety. The five practical stages include ordered sub-actions, exact amounts, expected observations, explanations and bench checks: one hulled strawberry mashed gently for two minutes; buffer of 90 cm³ water, 10 cm³ detergent and 3 g salt, using 10 cm³; gauze filtration; 5 cm³ filtrate with an equal volume of ice-cold ethanol kept in distinct layers; and fibre collection with a clean glass rod.
- [x] **Complete PowerPoint image archive** — All 22 extracted pictures appear with alternative text and captions, with relevant visuals also placed alongside the matching science and practical steps.
- [x] **Student knowledge checks** — Five questions have selectable options and a Check answer control. Answers remain hidden before checking. After checking, students see correct/incorrect feedback, the best answer and an explanation; a live counter reports checked questions and correct answers. Choosing a different option hides the previous result until it is checked again.
- [x] **Polished editorial design** — The page uses a consistent science field-journal treatment with a sticky translucent header, refined card surfaces and shadows, a single-column alternating image archive, interactive quiz cards, and strong display/body type hierarchy.
- [x] **Motion with accessibility support** — The 8n badge floats gently, a halo pulses and an orbit ring breathes. These animations are disabled for users who prefer reduced motion; scroll reveals also bypass motion in that mode.
- [x] **Validation** — TypeScript and static production build pass; the route manifest responds correctly; all 22 PowerPoint image assets return HTTP 200. The broad typography override was removed so small navigation and metadata labels keep their intended hierarchy.
